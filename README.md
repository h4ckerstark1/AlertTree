## 📖 About AlertTree

AlertTree aims to become an intelligent platform that combines:

- AI-powered intelligence discovery

## 🔐 Security Architecture

Security is one of the core engineering principles behind AlertTree.

Our security-first approach includes:

- Secure authentication and session management.
- HttpOnly cookie-based authentication.
- Server-side authorization and tenant isolation.
- CSRF protection and Origin validation.
- Rate limiting and audit logging.
- SSRF protection for monitored URLs.
- Secure secret and token management.
- Explicit user confirmation for sensitive AI actions.
- Restricted execution of automation workflows.
- Dependency auditing and security-focused testing.

We aim to build security into the architecture rather than add it as an afterthought.

**Security documentation:** [`docs/SECURITY.md`](docs/SECURITY.md)

## 🚀 Getting Started

### Prerequisites

- Node.js 22.12 or newer
- npm
- Git

### Installation

Clone the repository:

```bash
git clone https://github.com/h4ckerstark1/AlertTree.git
```

Navigate to the project:

```bash
cd AlertTree
```

Install dependencies:

```bash
npm install
```

Configure environment variables if required:

```bash
cp .env.example .env
```

Start the development server:

```bash
npm run dev
```

Open your browser:

```text
http://localhost:5173
```
